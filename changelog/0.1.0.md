# Create: Precise Controls 0.1.0

The first release adds exact keyboard entry to Create numeric controls while preserving the original scrolling and clicking behavior.

## Added

- Exact Create Factory Gauge recipe ingredient and output counts.
- Exact Factory Gauge stock-target entry from the value-settings board, including values beyond the normal 0-100 picker range with overflow-safe limits.
- Optional Create: Factory Controller support for exact regular recipe item/fluid amounts, non-crafting outputs, craft batch, request multiplier, request interval, and open-request limit.
- Optional Create: FluidLogistics support for exact resource recipe amounts.
- FluidLogistics 1.2.6 integration through its Create `FactoryPanelScreen` path.
- FluidLogistics 1.2.9+ integration through its dedicated `ResourceFactoryGaugeScreen`, including supported target/restock/additional-stock/promise-limit controls.
- Forge 1.20.1 / Create 6.0.8 support.
- NeoForge 1.21.1 / Create 6.0.11 support.
- Shared numeric parsing tests and English localization.

## Compatibility

- Create is required.
- Create: Factory Controller is optional; the documented integration follows its NeoForge 1.21.1 `1.2.1-alpha.3` recipe-screen layout.
- Create: FluidLogistics is optional; compatibility covers its 1.2.6 Create-screen architecture and its newer 1.2.9 dedicated resource-gauge architecture.
- The mod is client-only. Multiplayer servers do not need Create: Precise Controls installed.
