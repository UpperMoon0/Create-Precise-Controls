# Create: Precise Controls 0.1.1

This release fixes the NeoForge precise-input background blur and makes the supported optional-addon dev environments representative on both loader targets.

## Fixed

- NeoForge 1.21.1 precise numeric editors no longer invoke Minecraft's blurred in-world screen background. The live world remains sharp while the existing Precise Controls dim/modal backdrop remains visible.

## Development runtime coverage

- Forge 1.20.1 dev runs now include FluidLogistics 1.2.9 and Create: Factory Controller 1.2.1 as runtime-only optional dependencies.
- NeoForge 1.21.1 dev runs include the matching FluidLogistics 1.2.9 and Create: Factory Controller 1.2.1 builds.
- These additions affect development/testing only; neither addon becomes a required dependency for users.

## Compatibility verification

- Added published-binary contract verification for the exact Create: Factory Controller 1.2.1 jars used by both loader targets.
- CI SHA-512 verifies those jars before checking the private fields, methods, constants, and click entry points used by the optional reflection bridge.
- Forge verification covers the production-obfuscated `m_6375_(double,double,int)` click method; NeoForge verifies `mouseClicked(double,double,int)`.
- Documentation now records Create: Factory Controller 1.2.1 support on both Forge 1.20.1 and NeoForge 1.21.1 and includes the two-target screen-level runtime checklist.

## Supported targets

- Minecraft 1.20.1 / Forge / Create 6.0.8
- Minecraft 1.21.1 / NeoForge / Create 6.0.11

Create is required. Create: FluidLogistics and Create: Factory Controller remain optional integrations. The mod remains client-side only; multiplayer servers do not need Create: Precise Controls installed.
